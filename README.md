# Are We There Yet for AltStore Classic

This repository hosts public IPA downloads and the AltStore source for
**Are We There Yet**. The app's source code is in a separate private repository.

## Install

In AltStore Classic on your iPhone, open **Sources**, add the URL below, then
install **Are We There Yet** from the source:

`https://raw.githubusercontent.com/robertdb3/AreWeThereYet-AltStore/main/source.json`

AltStore signs the unsigned IPA with your Apple ID. If you use a free Apple ID,
the app needs to be refreshed within each seven-day period. Leave AltServer
running on your Mac and enable **Background Refresh** in AltStore. AltStore will
show new app versions from this source when a tagged release is published.

The files under `ipas/` are release binaries. This repository does not contain
the app's source code.
